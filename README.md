Objetivo: Armazenar, organizar e manipular dados de forma estruturada.

Conceitos principais:

Modelo relacional (tabelas, chaves primárias e estrangeiras)

SQL (SELECT, INSERT, UPDATE, DELETE)

Normalização e integridade referencial

Ferramentas comuns:

MySQL, PostgreSQL, SQLite

ORMs (Sequelize, Hibernate)

Exemplo de aplicação: Criar um banco para gerenciar usuários e pedidos de um e-commerce.
